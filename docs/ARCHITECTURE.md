# 第一版架构

Pawkit 是单机、单服主使用的 Windows 应用。现有原生 HTML/CSS/JavaScript 界面只负责输入、确认、状态显示与本地记录；`src-tauri/src/server.rs` 负责连接 RCON、验证操作参数、构造固定命令并返回服务端原文。前端无法提交任意 RCON 命令。

一次“连接”会验证地址和密码，然后只在 Rust 进程内保留连接信息。每次查询或操作建立一个短连接，防止断线后复用坏连接。每 15 秒的 `list` 刷新同时承担自动重连；手动重连与刷新使用同一组后台入口。`say` 和两种 `tp` 只执行一次，超时后标记“结果未知”，不自动重试。

服务器名称、地址和端口存在客户端本地；密码不写入配置和日志。前端只保留当天操作记录，并在跨日后清除旧记录。台式机和笔记本的状态互不共享。

地图下一版接入 `src-tauri/src/map.rs`，届时再根据实际 Mod/插件确定数据格式和更新方式。地图数据入口与 RCON 命令入口分开，避免让地图需求改变当前控制操作的接口。
